Privacy policy

Last updated: 15 October 2026

This policy covers the private upload tool of the YouTube channel Past Untold. The tool is used only by the channel owner.

What the tool accesses

With the owner's permission, the tool uses the YouTube API to upload and schedule videos on the owner's own channel and to read that channel's own statistics (for example views and click-through rate).

What is stored

The only thing stored is an access token on the owner's own computer or private cloud storage, so the tool can keep working without logging in again. No personal data of other people is collected, stored, sold or shared.

Third parties

Data obtained through Google APIs is not shared with anyone else. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke the tool's access at any time at https://myaccount.google.com/permissions.
